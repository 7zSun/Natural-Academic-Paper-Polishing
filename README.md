# Natural Academic Paper Polishing

面向科研论文写作、深度润色与学术审阅的 Skill。它关注的不只是语言是否正式，更关注研究问题、方法设计、实验依据和论证过程能否组成一篇自然、连贯、有说服力的学术文章。

**核心标准：让每一段都服务于研究主线，让每一句话都对理解论文有所帮助。**

[查看完整 Skill：SKILL.md](./SKILL.md)

## 1. 设计目标

帮助作者把论文写成围绕真实研究问题展开的学术文章，使读者能够清楚理解：

- 研究为什么值得开展；
- 现有研究取得了什么进展，还有哪些问题尚待解决；
- 本文针对什么问题进行了设计；
- 方法中的各项设计如何相互配合；
- 实验结果能够支持哪些结论；
- 研究的实际贡献与局限是什么。

写作结果应当是一篇完整的学术文章，而不是程序说明书、实验日志、技术报告或防御性审稿回复。

## 2. 适用任务

本 Skill 适用于科研论文的：

- **整体审阅：** 检查研究定位、文章主线、章节组织和证据链；
- **结构调整：** 重组摘要、引言、相关工作、方法、实验、讨论与结论；
- **逐节润色：** 改善语言、段落衔接、因果解释和论证完整性；
- **实验分析：** 检查实验目的、对照关系、指标解释与结论是否对应；
- **学术规范检查：** 核对文献引用、公式符号、图表编号和术语一致性；
- **投稿前审阅：** 从目标期刊或会议的写作要求出发，检查论文的完整性与表达质量。

## 3. 核心写作原则

### 自然、流畅、有逻辑

使用准确、常见的学术表达。控制句子长度，避免复杂句式堆叠，也避免把连续论述机械地拆成互不相关的短句。段落应有明确中心，段落之间应形成自然的因果、转折、递进或解释关系。

### 每句话都应具有论证价值

删除对理解研究没有帮助的重复说明、内部操作记录和无关的自我解释。判断一段内容是否必要，应看它是否推动读者理解研究问题、方法设计、实验结果或结论。

### 正面、直接地表达研究

避免没有实际论证需要的防御性写作。准确呈现研究取得的进展、尚存的差距和结论的不确定性，不夸大成果，也不刻意弱化成果。

### 讲清研究设计，而不是罗列工具

从真实应用场景和研究需求出发，再引入模型、算法与技术工具。明确区分已有工具的作用和本文真正增加的设计，不把常规工具调用包装成创新点。

### 让方法、实验和贡献相互对应

每项主要贡献都应有明确的问题背景、实际设计和对应证据。实验结论必须由真实结果支持，不能把相关性写成因果关系，也不能把趋势写成统计显著提升。

## 4. 推荐工作流程

1. **理解全文：** 梳理研究目标、应用场景、主要贡献、文章结构和已完成的实验。
2. **明确小节任务：** 判断当前内容需要回答什么问题，以及它与前后章节的关系。
3. **先调整逻辑：** 检查研究内容、段落顺序、方法与结果的对应关系，再处理语言。
4. **完整修改：** 按用户指定范围提供完整小节或完整稿件，保留已经确认且合理的内容。
5. **逐项复核：** 检查逻辑断裂、重复说明、防御性表达、自造概念、数据变化和术语不一致。

默认采用逐章节、逐小节推进的方式。除非作者明确要求，不应擅自一次性重写整篇论文，也不应自行增加实验、方法模块或贡献点。

## 5. 证据与学术规范

本 Skill 将事实准确性视为论文写作的底线：

- 不修改或编造实验数值，不推测缺失结果；
- 不混合不同测试集、评价口径或实验阶段的数据；
- 明确指标的计算对象、分母和评价方向；
- 正确表达置信区间、统计显著性与实际效果大小；
- 检查方法中的重要设计是否得到实验支持；
- 优先核对原始论文和权威出版来源，不编造引用；
- 统一公式符号、图表编号、模块名称和全文术语；
- 对无法确认的数据、实现或文献信息明确标注不确定性。

## 6. 如何使用

将仓库中的 [SKILL.md](./SKILL.md) 提供给支持 Skill 或自定义指令的 AI 助手，并在任务中说明论文材料、修改范围和目标。

建议同时提供：

- 完整论文，或当前章节及其前后相关内容；
- 与论述相关的实验结果、表格、图片和补充材料；
- 目标期刊或会议，以及需要遵循的格式要求；
- 本轮任务的范围，例如整体 Review、某一小节重写或引用核查；
- 已经确认、不希望随意改动的内容。

### 推荐任务提示

\`\`\`text
请按照 Natural Academic Paper Polishing 的要求审阅这篇论文。

先理解全文的研究场景、核心问题、方法设计、主要贡献和实验依据，
再检查当前章节承担的论证任务。优先调整研究逻辑和段落组织，
然后进行语言润色。

请特别检查：
1. 是否围绕真实研究问题展开；
2. 是否存在重复说明、无论证价值的句子和防御性表达；
3. 是否把工具调用或程序流程写成研究贡献；
4. 方法、实验和结论是否相互对应；
5. 数据、公式、文献、图表和术语是否准确一致。

请按我指定的章节逐节处理，给出完整修改稿。
不要编造实验结果、文献或研究内容，也不要擅自增加实验和方法模块。
\`\`\`

## 8. 语言与适用范围

Skill 正文以中文撰写，适用于中文和英文科研论文。具体修改时，应根据目标期刊或会议的语言习惯、学科术语和格式规范调整表达；自然流畅不意味着牺牲专业准确性。

---

**好的学术写作，不是把做过的所有事情都写出来，而是选择真正重要的研究内容，将问题、方法和证据组织成一个清楚、连贯、有说服力的故事。**
